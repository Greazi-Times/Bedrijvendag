# Generated route files and the type check

`resources/js/routes`, `actions` and `wayfinder` are generated by `php artisan wayfinder:generate` and are not in git.

**Why checks used to fail sometimes:** the generator deletes `routes/` and `actions/` and rewrites every file in two steps (content, then imports). The Vite plugin runs it on `vite build` and, in `npm run dev`/`composer dev`, whenever a `routes/**/*.php` or `app/**/Http/**/*.php` file changes. A `vue-tsc` run at that moment saw a missing module or a half-written file (reproduced by running generation in a loop during `vue-tsc`).

**What happens now:**
- `vite.config.ts` runs generation through `scripts/wayfinder-generate.mjs`, which takes a lock (`storage/framework/wayfinder.lock`, atomic `mkdir`, stale locks from dead processes are removed) and writes a completion marker (`resources/js/wayfinder/.generated.json`) only after a successful run.
- `npm run types` takes the same lock for the whole check, regenerates only if the marker is missing (an interrupted run) or a route/controller source is newer than it (`--regenerate` forces it), then runs `vue-tsc --noEmit`. Nothing is excluded from checking.
- `npm run wayfinder` generates manually under the lock.

A running dev server must be restarted once to pick up the new `vite.config.ts`; until then it still generates without the lock.
